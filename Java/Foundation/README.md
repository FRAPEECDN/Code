# Java Foundation Projects

This folder contains standalone projects for learning core Java and common application-building techniques. The projects are maintained and built independently; follow the README in each project directory for its requirements and commands.

| Project | What it demonstrates |
| --- | --- |
| [foundation-collection](foundation-collection/README.md) | Java collection implementations, CRUD, sorting, searching, streams, third-party collection libraries, and JavaTuples. Java 21 adds sequenced collections; Java 25 adds a Stream Gatherers example. |
| [foundation-gradle-template](foundation-gradle-template/README.md) | A reusable Gradle multi-project template that compiles shared code and optional version-specific code for Java 17, 21, and 25. |
| [foundation-io](foundation-io/README.md) | File I/O, Java object serialization versus JSON, and local TCP, UDP, HTTP, and WebSocket exchanges. Version-specific examples cover virtual threads and Java 25 preview structured concurrency. |
| [foundation-jdbc](foundation-jdbc/README.md) | Plain JDBC persistence for a project lifecycle model, with PostgreSQL connection pooling, H2 and SQLite repository examples, and encrypted database-credential configuration. |
| [foundation-maven-template](foundation-maven-template/README.md) | A reusable Maven reactor template for shared sources and Java 17, 21, and 25 modules. |
| [foundation-mongodb](foundation-mongodb/README.md) | MongoDB persistence and explicit BSON mapping, including repository operations, filtering, paging, bulk writes, aggregation, and transaction examples. |
| [foundation-oop](foundation-oop/README.md) | Object-oriented programming examples including enums, POJOs, records, sealed types, generics, exceptions, and collections, compared across Java versions. |
| [foundation-pojo](foundation-pojo/README.md) | An in-memory department and project management model with staff, projects, assignments, lifecycle rules, and an interactive console workflow. |
| [foundations](foundations/README.MD) | A tested quick reference to Java language and library fundamentals, including arrays, functional interfaces, I/O, exceptions, dates, and concurrency, across Java 17, 21, and 25. |

Many projects offer multiple Java-version variants. Their project-level READMEs describe which examples are shared, what changes between versions, and how to build and run each variant.
