# Java Projects

This folder contains independent Java learning projects and Spring Boot demos. It is a collection of projects, not a single build; each project has its own build files and instructions.

## Project areas

| Folder | What is here |
| --- | --- |
| [Foundation](Foundation/README.md) | Core Java examples and standalone demos for collections, object-oriented programming, I/O and networking, JDBC, MongoDB, and reusable build templates. |
| [Spring-boot](Spring-boot/README.md) | Spring Boot web and security demos, from a REST API with persistence to role-based, JWT, and TOTP authentication. |

Open the README in the project directory for its topics, Java version, prerequisites, and build, run, and test commands. Some projects include separate Java 17, 21, and 25 variants.
